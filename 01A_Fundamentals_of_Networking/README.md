# Experiment 1A — Fundamental Elements of Computer Networking

## Aim
To study the fundamental components of a computer network.

## Theory
A computer network is a group of interconnected devices that communicate and share resources.

### Network topologies
- **Bus:** All devices share one backbone cable.
- **Star:** Every device connects to a central switch or hub.
- **Ring:** Each device connects to two neighbouring devices.
- **Mesh:** Devices have multiple interconnections.
- **Tree:** A hierarchical combination of star networks.

### Transmission media
- **Guided:** Twisted-pair cable, coaxial cable and optical fibre.
- **Unguided:** Radio waves, microwaves and infrared.

### Networking devices
- **Hub:** Broadcasts received data to all ports.
- **Switch:** Forwards frames using MAC addresses.
- **Router:** Connects different IP networks.
- **Modem:** Modulates and demodulates signals.
- **Repeater:** Regenerates signals.

### RJ-45 cable colour coding
T568A: White-Green, Green, White-Orange, Blue, White-Blue, Orange, White-Brown, Brown.

T568B: White-Orange, Orange, White-Green, Blue, White-Blue, Green, White-Brown, Brown.

## Result
Studied network topologies, transmission media, networking devices and Ethernet cable colour coding.
