# Experiment 1B — File Sharing Within an Organization

## Aim
To share files between computers connected to the same local network.

## Procedure
1. Connect both computers to the same LAN.
2. Enable Network Discovery and File and Printer Sharing.
3. Share a selected folder and configure user permissions.
4. Access the folder from another computer using `\\COMPUTER-NAME\SHARE-NAME`.
5. Verify read/write access according to the permissions assigned.

## Result
Studied the procedure for sharing folders over a local network.
